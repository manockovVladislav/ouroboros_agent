# Audit Insight

Работать только через функции, объявленные в `tools.py` и реализуемые публичным шлюзом `ouroboros_tools.py`.

## Порядок работы

1. Уточнить область проверки и разрешённые источники.
2. Профилировать набор данных перед применением правил.
3. Применять формальные правила только к совместимым и валидным входам.
4. Использовать поиск документов для критериев и нормативных оснований.
5. Получать Evidence по идентификатору, не читать внутреннее хранилище напрямую.
6. Различать подтверждённое нарушение правила и аномалию для проверки.
7. Формировать AuditFinding только при наличии достаточных доказательств.
8. Создавать отчёт из проверенных наблюдений и явно указывать ограничения.

Не выполнять произвольный Python, не обходить ограничения путей и не утверждать факты, которые нельзя проследить до Evidence.

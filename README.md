# Audit Insight Agent

Интеллектуальный агент на базе **Ouroboros** для автоматизированного поиска аудиторских рисков, отклонений, противоречий и потенциальных направлений проверки.

## Источники данных

Агент объединяет и анализирует:

- требования регуляторов и внешние нормативные документы;
- внутренние нормативные документы;
- выгрузки и реплики информационных систем;
- синтетические и обезличенные внутренние данные;
- результаты предыдущих проверок и проектов;
- материалы из Confluence;
- программный код и документацию из Bitbucket;
- протоколы встреч и обсуждений;
- текстовые, табличные, графические и другие источники.

## Результаты работы

Агент выполняет предварительную обработку и исследовательский анализ данных (EDA), выявляет взаимосвязи между источниками и формирует:

- аудиторские инсайты и гипотезы;
- возможные нарушения и противоречия;
- направления дальнейшей проверки.

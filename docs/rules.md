# Декларативные правила

Каждое правило должно храниться вне Python-кода и включать как минимум идентификатор, версию, назначение, входы, условие, серьёзность и критерий. До реализации требуется определить JSON Schema или эквивалентную строгую схему.

Rule engine должен разрешать только ограниченный язык выражений. Произвольный Python, shell-команды и неограниченный файловый доступ запрещены.

Результат правила должен быть воспроизводимым: входные строки, значения, формула, версия правила и итог сохраняются как Evidence. Срабатывание валидного правила трактуется как подтверждённое отклонение; результат anomaly detector — только как сигнал для проверки.

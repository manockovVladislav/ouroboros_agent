# Case packages

Каждый синтетический или прикладной сценарий является автономным пакетом:

```text
cases/<case_name>/
├── data_sources.yaml   # источники, форматы, ожидаемые поля и ключи
├── relationships.yaml # связи источников и поля сопоставления
├── rules/              # декларативные правила сценария
└── prompts/            # контекст и инструкции, не исполняемая логика
```

Ядро не импортирует Python-модули из case-пакета. Добавление сценария сводится
к YAML/Markdown-файлам. Входные файлы в case-пакет не копируются: источники
всегда находятся в `data/`, а дополнительная постоянная база знаний — в
`knowledge/`.
